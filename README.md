# clubVERSE-assets

clubVERSE で使う画像の公開ミラーです。VRChat のワールドから読み込むために公開しています。

- 配信URL: `https://loy6161.github.io/clubVERSE-assets/images/...`
- 中身は非公開リポジトリ `clubVERSE` の `images/` を GitHub Actions で自動同期したものです
- **このリポジトリを直接編集しないでください。** 更新は `clubVERSE` 側で行うと自動で反映されます

VRChat の許可ドメイン (`imageHostUrlList`) に `*.github.io` が含まれるため、
「Allow Untrusted URLs」を OFF のままでも画像が表示されます。
